PP-OCRv6 tiny text detection and recognition models
===================================================

Gege Dictionary reads the text of screenshots with the PP-OCRv6 "tiny" models of PaddleOCR. They
are part of the program (they are not downloaded), and they run on this PC only.

  PP-OCRv6_tiny_det   text line detection
  PP-OCRv6_tiny_rec   text line recognition, with its character dictionary

  https://huggingface.co/PaddlePaddle/PP-OCRv6_tiny_rec

The ONNX Runtime library that runs them, and the Microsoft Visual C++ runtime that it needs, are
described in README-runtime.txt in this folder.
