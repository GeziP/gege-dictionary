# 鸽鸽词典 V1.4.2

本版本修复“测试连接正常，翻译却长时间加载”以及版本信息缺失问题。

## 修复

- 模型已返回流式结束标记时立即完成，不再等待连接自然关闭或超时。
- 流式请求失败后不再自动发起第二次完整请求，避免 60 秒超时被放大为约 120 秒。
- 请求过程显示已等待时间和当前超时上限，失败时直接显示可操作的错误。
- 版本号改为编译时内置，即使原生版本 API 读取失败也不会显示省略号。
- 主界面侧边栏常驻显示版本，更新页同时显示版本和 Windows x64 平台信息。

## 验证

- 使用本机已加密配置的 DeepSeek Key 完成计算机领域真实流式解析，15.98 秒返回 8245 字节并通过 JSON 解析。
- 前端 lint 和生产构建通过。
- Rust 测试 62 项通过，真实端到端测试 1 项通过。
