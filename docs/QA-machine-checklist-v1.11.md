# v1.11 实机验收清单

适用版本：1.11.0  
目的：v1.11 是一次体验打磨，改动集中在窗口外壳、生词库、复习、设置与查词窗口。其中系统标题栏的主题跟随、查词窗口与主窗口之间真实的导航、键盘与读屏的手感、旧版本升级，都依赖真实的窗口和系统，自动化门禁够不到；在装有 Windows 的真机上逐项验收。主路径（复制即查、OCR、Anki、更新通道）仍按 `docs/QA-machine-checklist-v1.6.md` 的 A–E 组执行，托盘与朗读按 `docs/QA-machine-checklist-v1.9.md` 的 F–K 组执行，备用模型、批量补全等按 `docs/QA-machine-checklist-v1.10.md` 的 L–R 组执行（这些与 v1.10 相比没有改动，抽查即可）。

## 环境前置

| 项 | 要求 |
|---|---|
| OS | Windows 10 1809+ / Windows 11 |
| 模型服务 | 一个可用的主模型（用于查词）。S 组与 V 组要把 Key 故意改错一次，改完记得改回来 |
| 本地服务 | 可选：本机运行的 Ollama 或 LM Studio（`http://127.0.0.1:11434/v1`），用于 V3；没有的话 V3 跳过 |
| 数据 | 一份 v1.10.0 的数据目录（有生词、复习进度、查词历史），用于 X 组；T9 与 V8 需要一台**没有装过鸽鸽词典**的机器、另一个 Windows 用户账户或虚拟机，不要清空自己的数据 |
| 屏幕 | 一块能把窗口缩到约 800×520 的屏（用于 T11） |
| 安装包 | `Gege-Dictionary_1.11.0_x64-setup.exe` 或本地 `npx tauri build` 产物；X 组需要先装 v1.10.0 |

## S. 窗口与导航

| # | 步骤 | 期望 |
|---|------|------|
| S1 | 启动应用，打开主窗口 | 窗口顶部只有系统标题栏一条；内容区顶部没有第二条带窗口按钮的标题栏 |
| S2 | 用系统标题栏拖动、最大化、还原、最小化窗口；点 × | 都正常；点 × 后应用留在系统托盘里，从托盘图标能再打开主窗口 |
| S3 | 在窗口里切换外观主题（浅色 / 深色 / 跟随系统；设置 →「外观与朗读」里也有） | 系统标题栏的颜色跟着变：深色主题是深色标题栏，浅色主题是浅色标题栏 |
| S4 | 选「跟随系统」，再到 Windows「设置 → 个性化 → 颜色」切换应用模式 | 应用与系统标题栏一起变 |
| S5 | 把主模型的 Key 故意改错，复制一个没查过的英文词让查词窗口弹出；在错误卡片上点「去设置」 | 主窗口来到「设置 → 模型服务」 |
| S6 | 接着在主窗口依次点左侧的「生词库」「今日回顾」「学习洞察」 | 每一页都能正常打开；不会停在设置页（v1.10.0 的缺陷） |
| S7 | 主窗口已经在「生词库」时，再从查词窗口点一次「去设置」 | 主窗口来到设置页，之后同样可以切回别的页 |
| S8（有更新或有警告时） | 有「发现新版本」条或启动警告条时，看查词窗口 | 这两种提示只在主窗口出现；启动警告条点关闭后，本次运行内不再出现，重启后若问题仍在会再出现 |

## T. 生词库

| # | 步骤 | 期望 |
|---|------|------|
| T1 | 选中一个词，点删除 | 底部提示「已删除「xxx」」并带「撤销」；约 8 秒后消失；鼠标放在提示上时不消失，移开后重新计时 |
| T2 | 再删一个词，点「撤销」；再试一次，快速连点「撤销」两下 | 词回来，内容、标签、笔记都在；提示写明复习进度重新开始；连点只恢复一次 |
| T3 | 选中三个词删除，再撤销 | 提示写「已删除 3 条生词」；撤销后三个都回来 |
| T4 | 打开一个没有标签的词，在详情的「添加标签」框里输入 `ab`；已有别的标签可作候选时按 Enter | 添加的是 `ab`，不是候选的第一项；新标签立刻出现在词条与筛选面板里 |
| T5 | 打开筛选面板的掌握度 | 新词、巩固中、熟悉、已掌握四档都能选；选「熟悉」能筛出熟悉的词 |
| T6 | 在详情面板里用「阅读字号」的缩小 / 放大，走到两头 | 字号在 10 到 22 之间变化，到头后按钮变灰；切到别的页再回来、重启应用后仍是这个字号 |
| T7 | 点工具栏的「导入」，用键盘 Tab 到文件框，按 Enter 或空格选一份 CSV（列名用「单词, 释义」这样的中文名也行） | 文件框能用键盘选；列自动对应好；导入完成后列表里立刻出现新词，不需要手动刷新；对话框里没有「拖放」的说法 |
| T8 | 在搜索框里搜一个不存在的词 | 表格里写「没有匹配的生词」，并有「清除搜索和筛选」；点它之后搜索与筛选都清空 |
| T9（没装过的机器） | 第一次打开生词库 | 写「生词库还是空的」、词是怎么进来的，以及「导入已有词表」；到设置里把「划词即查」关掉后再看，改成指向设置的说明 |
| T10 | 导入一份只有「词 + 释义」的 CSV，看生词库顶部的补全提示，点它的「暂时不再提示」，切到别的页再回来；再导入更多只有释义的词 | 点过之后提示消失，回来时也不出现；有更多词待补全时才重新出现 |
| T11 | 把窗口缩到约 800×520，再选中几个词 | 工具栏的搜索框收窄，但按钮保持形状；选中栏的按钮换到第二行，没有被挤变形 |
| T12 | 看生词库顶部的复习横幅 | 写明有几个词到期，以及下次复习是什么时候 |
| T13 | 在没有阅读会话的数据下打开「阅读会话」 | 写「还没有阅读会话。连续查词（相邻两次不超过 N 分钟）会自动归为一个会话。」 |

## U. 复习与洞察

| # | 步骤 | 期望 |
|---|------|------|
| U1 | 今日回顾里翻开一张卡 | 页头写「第 N 档」；整页没有「Box」字样 |
| U2 | 学习洞察 →「复习档位」 | 三档写「第 1 档 / 第 2 档 / 第 3 档」，各带「1 天后再见」「3 天后再见」「7 天后再见」 |
| U3 | 答完一轮，没有别的到期词 | 写「本次回顾完成」与「下次复习：…」；没有「继续复习全部到期词」；有「回到生词库」 |
| U4（还有到期词时） | 答完一轮，但还有到期词 | 写「还有 N 个词已经到期」，并有「继续复习全部到期词」；点它继续出下一批 |
| U5 | 翻开卡片，用 Tab 把焦点移到「朗读」按钮，按空格；再把焦点移到一个答案按钮，按空格；最后让焦点不在任何按钮上，按空格 | 前一次只朗读，不翻面；第二次选的是这个答案，不是翻卡；第三次翻卡 |

## V. 设置与首次引导

| # | 步骤 | 期望 |
|---|------|------|
| V1 | 在「外观与朗读」改一个设置（如朗读语速） | 页签旁依次出现「保存中…」与「已保存」，几秒后消失；不是只有「数据与隐私」页签才有 |
| V2 | 在「模型服务」里选「本地网关」预设（Key 框为空时） | Key 框写「这个服务不校验 Key，已填入占位符，保持原样即可」；不用输入 Key 就能保存 |
| V3（有本地服务时） | 点「测试连接」，再复制一个英文词 | 连通并显示延迟；查词窗口能给出结果 |
| V4 | 再选「OpenAI」预设 | Key 框是空的（占位符没有带过去）；旁边有「如何获取」，点它在浏览器里打开 OpenAI 的 Key 页面 |
| V5 | 把 Base URL 手动改成 `https://api.openai.com/v1/`，再改成 `HTTPS://API.OPENAI.COM` | 两种写法都被识别成 OpenAI 预设，并有「如何获取」链接 |
| V6 | 已保存 Key 的状态下，用鼠标点 Key 框标题旁边的字；再点「更换 Key」 | 点字不会清掉已保存的 Key；点「更换 Key」后输入框清空并获得焦点，可以直接输入 |
| V7 | 「热键与取词」里点「检测 OCR 可用性」 | 结果显示在页面里，没有系统弹窗 |
| V8（没装过的机器） | 首次引导里选「本地网关」，再退回选一个需要 Key 的服务 | 选本地网关后可以不填 Key 直接继续；选需要 Key 的服务时必须填 Key，而且框里没有 `ollama` |

## W. 查词窗口

| # | 步骤 | 期望 |
|---|------|------|
| W1 | 查一个词，点头部的「放大字体」两次，关闭窗口，再查一个词 | 新打开的窗口保持放大后的字号；范围 10–18 |
| W2 | 让查词窗口开着，在主窗口里改一个设置（如朗读语速），回到查词窗口再调一次字号，然后看主窗口的设置页 | 主窗口里刚改的设置没有被盖掉 |
| W3 | 查一个有例句的词（如 run），看例句里的高亮 | 只高亮 run / runs / running 一类的词形；不在 prune 这样的词中间高亮 |
| W4 | 用鼠标点头部的「缩小字体」「放大字体」「逐句对照」「钉住窗口」与关闭 | 点击区域够大，不容易点偏 |
| W5 | 在查询进行中与完成后各看一次回答的末尾 | 「AI 生成内容，专业术语和代码请以官方文档为准」只在查询完成后出现，在回答的最后 |
