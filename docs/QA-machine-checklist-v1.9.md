# v1.9 实机验收清单

适用版本：1.9.0  
目的：v1.9 新增或修复的原生路径（托盘、语音、旧备份恢复）无法被自动化门禁覆盖；在装有 Windows 的真机上逐项验收。主路径（复制即查、OCR、Anki、更新通道）仍按 `docs/QA-machine-checklist-v1.6.md` 的 A–E 组执行。

## 环境前置

| 项 | 要求 |
|---|---|
| OS | Windows 10 1809+ / Windows 11 |
| 语音 | 系统已安装至少一个英文语音；若想验证「没有英文语音」的退路，另备一台没有的机器或临时禁用 |
| 数据 | 一份 v1.8.0 时代的数据目录（含自动备份 `backups/gege-backup-*.db`），用于 J 组 |
| 安装包 | `Gege-Dictionary_1.9.0_x64-setup.exe` 或本地 `npx tauri build` 产物 |

## F. 托盘监听开关

| # | 步骤 | 期望 |
|---|------|------|
| F1 | 托盘右键 → 取消勾选「划词即查」 | 勾选消失；复制英文不再弹窗；回到主窗口后，设置 → 捕获里的「划词即查」开关同步为关 |
| F2 | 重新勾选 | 复制英文恢复弹窗 |
| F3 | 托盘 →「暂停 30 分钟」 | 勾选消失，不弹窗；此时再点一次「划词即查」→ 勾选回来、恢复弹窗（暂停被取消） |
| F4 | 暂停期间在托盘里点两次「划词即查」（先打开、再关掉），等满 30 分钟 | 到点后保持关闭：你的选择比暂停的到期更优先 |
| F5 | 暂停两次（间隔几分钟） | 以第二次为准重新计时 |
| F6 | 监听已关闭时点「暂停 30 分钟」 | 无效果；到点也不会被打开 |

## G. 朗读与语音

| # | 步骤 | 期望 |
|---|------|------|
| G1 | 设置 → 朗读 | 下拉列出本机已安装的语音，与「Windows 设置 → 时间和语言 → 语音」一致 |
| G2 | 选「自动（优先英语语音）」点「试听」 | 英文语音念 *The protocol degenerates into a livelock.* |
| G3 | 试听进行中再点「停止」 | 立即静音，按钮恢复「试听」 |
| G4 | 复制含弯引号的英文（`don’t`、`it’s`、`“quoted”`）后在查词卡里点朗读 | 正常发声，没有静默失败 |
| G5 | 朗读一句时点另一句的朗读 | 前一句被替换，不叠音 |
| G6 | 试听的声音与查词卡里朗读的声音 | 是同一个声音、同一个语速 |

## H. 查词历史

| # | 步骤 | 期望 |
|---|------|------|
| H1 | 查几个词后打开 生词库 → 历史 | 按天分组、最新在上；同一个词再查一次，出现 ×2 并移到最上 |
| H2 | 点击一条 | 查词窗打开；答案仍在缓存里时没有等待 |
| H3 | 搜索框输入释义里的词 | 只显示匹配项，计数为「匹配 n / m 条」 |
| H4 | 删除一条；清空历史（确认） | 立即消失；已收藏的词不受影响 |
| H5 | 设置 → 数据 → 关闭「记录查词历史」后再查词 | 历史页不再增加，顶部提示「查词历史已关闭」；已有记录仍可查看与删除 |

## I. 学习洞察

| # | 步骤 | 期望 |
|---|------|------|
| I1 | 全新数据目录首次打开「学习洞察」 | 显示「还没有学习记录」的引导，而不是满屏零 |
| I2 | 查词、收藏、做几张复习卡后切回该页 | 窗口重新获得焦点时数字自动更新；连续学习至少 1 天 |
| I3 | 切换 7 / 30 / 90 天 | 曲线与「近 N 天」数字随之变化 |
| I4 | 点「去复习」 | 跳转到复习页 |

## J. 升级、备份与数据

| # | 步骤 | 期望 |
|---|------|------|
| J1 | 用 v1.8.0 的数据目录启动 v1.9.0 | 先产生迁移前备份；生词、复习进度、设置全部保留；历史页为空 |
| J2 | 设置 → 数据 → 恢复一份 v1.8.0 时代创建的自动备份 | 恢复成功并升级到 v6；历史页可用 |
| J3 | 再次查一个已收藏、已设置过掌握度与备注的词，然后保存 | 掌握度、备注、标签不变；查询次数 +1；没有出现重复词条 |
| J4 | 词条详情 →「重新解析」 | 真的请求模型（有等待）；完成后显示用了哪个模型；失败时给出具体原因且词条不变；「回滚」能还原 |
| J5 | 查词窗口里在上下文输入框按空格、在标签框按 Enter | 空格不触发朗读；Enter 只保存一次 |
| J6 | 收藏后立刻点「撤销」 | 词真的从生词库里消失（再打开生词库确认） |
| J7 | 设置页「用量」 | 「今日查询」随每次出结果增加（缓存命中也算），而不是随收藏增加；token 不再恒为 0 |
