# 鸽鸽词典 V1.6.0

本版本补上 Ctrl+C 的能力天花板与学习闭环转化：系统级截图 OCR、可选 Anki Connect 同步，以及查词窗上下文与体验补强。

## 截图 OCR（#22 / #13）

- 默认热键 `Ctrl+Shift+O`，托盘菜单「截图取词」，全屏框选。
- 使用 Windows 系统 OCR（`Windows.Media.Ocr`）本地识别，截图不落盘、不上传。
- 识别结果进入与剪贴板相同的过滤 / 查词 / 生词库 / 本地统计管道。
- 设置页可开关、立即框选、检测 OCR 可用性。

## Anki Connect（#23）

- 默认关闭；仅连接本机 `127.0.0.1:8765`。
- 设置页可测试连接、选择牌组与笔记类型。
- 生词详情可发送到 Anki；Front=词条，Back=译文与语境；按牌组+词条去重。

## 查词体验（#24 / #25）

- 可在查词窗编辑上下文并「用新上下文重新解析」。
- 重用查词窗不再 `location.reload()`，减少闪白。
- 本地统计新增 `ocr_*` / `anki_*` 事件。

## 工程

- 版本三处同步 1.6.0；Rust 测试与前端检查随 PR CI 门禁。

## 验证

- `cargo test --lib` 全绿；`tsc` / `lint` / `build` 通过后发布。
- OCR 与 Anki 需在装有系统英文识别包 / AnkiConnect 的 Windows 实机验收。
