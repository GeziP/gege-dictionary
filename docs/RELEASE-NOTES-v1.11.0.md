# 鸽鸽词典 V1.11.0

本版本是一次体验打磨：没有新的取词入口，也没有数据库升级。把日常使用里一路磕磕绊绊的地方理顺——窗口里只剩一条标题栏，删错的词可以撤销，没有标签的词也能打标签，设置有没有保存成功看得见，本地模型不必再凑一个 Key。

## 新功能

### 删除可以撤销

- 在生词库里删除词之后，底部的提示条上有「撤销」，停留约 8 秒；鼠标指着它或键盘停在上面时不会消失。撤销恢复的是词的内容；**复习进度会重新开始**，提示里会写明这一点。
- 删除失败时会说明原因，而不是什么都不发生。

### 没有标签的词也能打标签

- 词条详情里，没有标签的词现在也能直接添加标签。输入后按 Enter 添加的是你输入的内容，而不是候选列表的第一项。

### 本地模型不用再凑一个 Key

- 「本地网关」预设（Ollama / LM Studio）不校验 Key，但应用在没有 Key 时不会发起查词，以前只能随手填一个。现在选择它会自动填入占位符 `ollama`，并写明「这个服务不校验 Key，已填入占位符，保持原样即可」；首次引导页同样。
- 之后改选需要真实 Key 的服务时，这个占位符会被清掉，不会被当作 Key 发给别的服务。

### 每个服务的 Key 去哪里申请

- 预设服务旁边有「如何获取」链接，指向该服务生成 Key 的页面。
- 服务地址不论怎么写（末尾有没有斜杠、带不带 `/v1`、大小写）都会被识别成同一个预设，所以手动填的地址也会标出预设并给出链接。

### 设置有没有保存，每一页都看得见

- 保存状态（保存中 / 已保存 / 失败及原因）显示在设置页签旁边，所有页签都能看到；以前只有「数据与隐私」页签有。
- 保存失败的原因只报一次，可以关闭，不再带「Error:」前缀。

### 空词库与空结果会说话

- 生词库里一个词都没有时，页面写明词是怎么进来的（选中文字后复制，查词窗口会弹出；「划词即查」关着时指向设置），并给出「导入已有词表」。
- 搜索或筛选后没有结果时，写明为什么，并给出「清除搜索与筛选」。

### 查词窗口记住字号

- 查词窗口里调的字号（10–18）会被记住，下次打开还是这个大小。它存在本机的浏览器存储里，而不是设置里：查词窗口手里是打开时那份设置的旧拷贝，从那里保存设置会把主窗口里后来改的东西盖掉。

## 变化与修复

### 窗口与通知

- **只有一条标题栏**：去掉了窗口里自绘的那一条。系统自己的标题栏就在它上面，而且能拖动、最大化、关闭到托盘。系统标题栏跟随应用的浅色 / 深色主题（需要新的窗口权限 `core:window:allow-set-theme`，已加进 capability）。
- **查词窗口的「去设置」**：以前点过之后，主窗口的每个页签都显示设置页，像被锁住了；现在是真的跳转。
- 启动警告不再盖在页面上方，可以关闭（本次运行内不再出现）。更新提示与启动警告只出现在主窗口。
- 提示条：失败时读屏立即播报，其余的等读屏空闲；鼠标指着或键盘停在上面时不消失；带操作的提示在淡出过程中不会被连点两次。
- 弹出的对话框把键盘焦点留在里面，关闭时还给原来的位置。

### 生词库

- **筛选能选「熟悉」**：掌握度筛选以前缺了这一档，现在四档齐全，和详情面板用的是同一份列表。
- **字号只有一个控件**：原来有两个，其中一个没有作用。现在只留详情面板里的一个，保存在设置里。
- **导入**：文件框可以用键盘操作；列按常见名称（中英文都认）对应；导入完成后列表会自己刷新；对话框不再承诺并不支持的拖放。
- 「N 个词还没有义项和例句」的补全提示可以收起；之后待补全的词比收起时更多了才会再出现。
- 复习横幅写明有几个词到期、下次复习是什么时候。
- 阅读会话里，加载、打开、打标签、导出、加入复习失败时会说明；空列表会说明是什么意思；打标签不再把显示的词清空。
- 行内编辑只提交一次，不论是回车还是点别处结束的。
- 表格按列排序时向读屏说明排序方向，搜索框有了名称；窄窗口里工具栏保持形状，选中栏的按钮换到第二行，而不是被挤变形。

### 复习

- 「Box 1 / 2 / 3」在复习页与学习洞察里改称「第 1 / 2 / 3 档」。
- 一轮答完不再是死胡同：写明还有没有到期的词、下一次复习是什么时候；只有真的有到期的词才给「继续复习」，并给出回到生词库的入口。
- 空格键：焦点在朗读、答案按钮或链接上时，空格按下的就是它们；只有焦点不在任何按钮上时才翻卡。

### 设置

- **「更换 Key」不会再误触**：Key 框的标题以前把「更换 Key」按钮也包了进去，点标题旁边的字就会触发它，把已保存的 Key 清掉。现在标题只是标题；点「更换 Key」后焦点直接进入输入框。
- OCR 可用性检查的结果直接显示在页面里，不再弹系统对话框；OCR 热键输入框有了名称，没有对应控件的小标题改成了普通文字。

### 查词窗口

- 头部按钮的可点击范围加大（从 16–20 像素到 20–24 像素）。
- 例句里高亮词形时，不再把别的词中间的相同字母当成目标词（例如 prune 里的 run）。这个组件现在是独立文件，带测试。
- 「AI 生成内容，专业术语和代码请以官方文档为准」放在回答的末尾，并且只在查询完成后出现。
- 模板名只在有的时候显示，不再写「未知」。

## 工程

- 前端测试增加到 45 个文件 700 项；窗口外壳、生词库、复习、设置和查词窗口的组件都有了测试。
- 新增的公共部件：`useFocusTrap`（对话框焦点）、`useToast` 的暂停与操作、`SettingsSaveStatus`、`LibraryEmpty`、`lib/import-columns.ts`（导入列名对应）、`lib/reader-size.ts`（阅读字号范围）、`utils/format.ts` 的 `errorText` 与 `dueText`。
- Rust 端没有改动，只有 capability 里多了一项权限 `core:window:allow-set-theme`（已对照锁定的 tauri 2.11.5 核对这个权限存在）。schema 仍是 v7，没有数据迁移。
- 版本三处同步 1.11.0（`package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`，两个锁文件随之更新）。

## 升级说明

- **没有数据迁移**：schema 仍是 v7，设置不变，应用内更新即可；退回 v1.10.0 不需要处理数据目录。
- 窗口里自绘的标题栏没有了：最大化、最小化、关闭到托盘现在都在系统标题栏上。
- 撤销删除恢复的是词的内容，复习进度会重新开始（恢复是整条写回，不带回原来的进度）。
- 选择「本地网关」预设时填入的占位符 `ollama` 和别的 Key 一样保存、随请求发给本地服务；改选需要真实 Key 的服务时会被清空。
- 查词窗口的字号（`gege.lookup.fontSize`）与收起补全提示时的待补全词数（`gege.enrichment.prompt-hidden-at`）存在本机浏览器存储里，不在设置里，也不在备份里。
- 清空数据、清除历史、术语表这几处的确认框仍是系统对话框，本版没有改。

## 已知问题

- 界面样式（`src/index.css`）里引用了 Inter、Gentium Book Plus 与 JetBrains Mono 三个网络字体，但应用的内容安全策略（`src-tauri/tauri.conf.json` 里的 CSP）不允许加载外部样式与字体，所以安装版显示的是系统后备字体；开发时能联网才会看到这三个字体。本版没有改动这一点。

## 验证

开发机上的自动化检查通过：`npx tsc --noEmit`、`npm run lint`、`npm run build`、`npm test`（45 个文件 700 项）。Rust 端本版没有改代码；`cargo clippy --locked --all-targets -- -D warnings`、`cargo fmt --check` 与 `cargo test --locked --lib` 由 CI 与发布流程执行，不通过就不会合并或发布。

自动化测试够不到系统标题栏的主题跟随、查词窗口与主窗口之间真实的导航、读屏与键盘的手感，所以请按 `docs/QA-machine-checklist-v1.11.md` 的 S–X 组在 Windows 实机验收。其中最需要实机确认的是：

- 窗口里只有系统标题栏一条；切换浅色 / 深色后，系统标题栏的颜色跟着变。
- 在查词窗口里点「去设置」，主窗口跳到设置页之后，其它页签仍然可以正常切换。
- 删除几个词再点「撤销」，词回来了，提示里写明了复习进度重新开始。
- 选「本地网关」后不用输入 Key 就能保存；改选 OpenAI 后 Key 框是空的。
- 点 Key 框标题旁边的字不会清掉已保存的 Key。
- 用旧版本的客户端检查更新、下载、安装并重启，确认签名校验与更新通道正常（`docs/RELEASE.md` 第 6 步）。
