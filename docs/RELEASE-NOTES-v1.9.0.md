# 鸽鸽词典 V1.9.0

本版本先还「信任债」：修掉会悄悄改坏用户数据、能被构造文本利用、以及界面说了却没做的问题；再补上两个反馈回路——查过的词找得回（查词历史），学习看得见（学习洞察）。

## 新功能

### 查词历史

- 生词库新增「历史」页：查过的内容按天分组，可搜索，标出已经收藏的，点一下即可再次打开——答案还在缓存里就直接出现，不再请求模型。
- 同一个词（不分大小写与空格）只占一行并累计次数；最多保留最近 500 条。
- 默认开启，**只保存在本机**。在「设置 → 数据 → 查词历史」可以关闭、查看条数、一键清空；也可以在历史页删除单条。

### 学习洞察

- 侧边栏新增「学习洞察」：连续学习天数（今天还没学不算断）、近 7 / 30 / 90 天的活动曲线（查词、收藏、复习）、掌握程度分布、复习档位与答对 / 答错、常查的词、易错的词、生词来源。
- 数据全部来自本机已有的记录；回到窗口时自动刷新。

### 托盘与朗读

- 托盘「划词即查」的勾选与真实状态一致；「暂停 30 分钟」可以随时取消，到点也不会把你中途手动关掉的监听又打开。
- 朗读优先选英文语音（此前会用系统默认的中文语音读英文）；设置页列出本机已安装的语音，并用真正朗读的 Windows 引擎试听，带「停止」。

## 修复

### 安全

- **朗读文本可被构造成命令**：文本此前被拼进 PowerShell 脚本，只转义了 ASCII 引号，而弯引号（U+2018 / 2019 等）同样会结束字符串。含弯引号的文本会让朗读静默失败，精心构造的文本能执行任意命令。现在文本、语音、语速通过环境变量传入，脚本是固定的。
- 模型输出解析失败时，日志不再包含输出的前 500 个字符，只记录长度与出错位置。

### 数据

- **再次查已收藏的词不再重置它**：此前会把掌握度、备注、标签重置、丢掉 Anki 关联，还可能生成重复词条。现在保存是合并：内容刷新，掌握度、备注、标签、收藏时间、来源与 Anki 关联保留，查询次数加一。
- Anki 回写的 note id 此前按位置配对，可能写到别的词上；现在按词自身配对，并在一个事务内写入。
- 批量改掌握度 / 标签、删除词条、会话批量打标签都改为单事务；批量导入 3000 行到 3000 词的词库，从约 10 秒降到约 1 秒。
- 「撤销收藏」此前只把按钮翻回去，词仍在库里；现在真的删除或还原。
- 恢复旧版本做的备份不再失败：恢复按备份自身的版本校验，复制进来后立即升级；来自更新版本的备份会被明确拒绝。

### 查词窗口

- 键盘规则：不再在文本框里吞掉空格去朗读、不再因 Enter 保存两次、输入法确认候选词的 Enter 不再触发保存；保存进行中按钮立即禁用。
- 查词窗口与 OCR 窗口冷启动时不再加载整个生词库。
- 错误提示按真实原因给出建议：此前 403 / 404 / 429 / 5xx 与超时都说「请检查网络」。首次配置的「测试连接」现在显示真实延迟与真实失败原因（此前成功时写死 412ms，任何失败都说 401）。
- Anthropic 协议下回答因 `max_tokens` 被截断时，如实提示被截断，而不是「JSON 解析失败」。

### 不再说谎的几处

- 词条详情的「重新解析」此前只转一圈，改一下收藏时间，却声称「已用某模型重新解析」；现在真正重新请求模型，只替换模型写的内容，掌握度、备注、标签等保留，失败如实报告，并且可以回滚。
- 用量统计：「今日查询」此前其实是「今日保存」，token 恒为 0；现在每次出结果都计一次（缓存命中不耗 token），token 按文字类型估算。**升级后这些数字的含义变了，会和以前的数字对不上。**

### 界面与性能

- 带透明度的主题色类（如 `bg-danger/5`、`border-line/60`）此前不产出任何样式，所有错误横幅都没有底色，现已修复。
- 生词库搜索：输入框跟手，列表在浏览器有空时跟上；列表行不再每次按键整体重渲染。
- 表头「全选」只针对当前列出的词；已选但被筛掉的词不再让它误判成「已全选」。

## 工程

- schema 升到 v6（新增 `lookup_history`）；升级前自动备份，失败回滚。
- `cargo clippy --all-targets` 零警告：10 个参数的函数与 10 元素元组改为 `ModelCall` / `LookupPlan` 结构体。
- 删除原型期无人引用的演示与 mock 代码（约 2700 行）与两张只在演示里用的壁纸，安装包更小。
- 耗时预算类测试改为「在绝对预算内，或与同机器上已知线性开销的参照相比成比例」，在繁忙机器上不再误报。
- 版本三处同步 1.9.0；`package.json` 补上实际在用的 `autoprefixer` 与 `postcss`。

## 升级说明

- 首次启动 v1.9.0 会把数据库从 v5 升到 v6，并先自动备份；失败会回滚。
- 查词历史默认开启。不想保留的话，在「设置 → 数据 → 查词历史」关闭，并可一键清空已有记录。「导出全部数据」得到的完整快照中也包含历史，分享前请先清空。
- 用量统计的含义改变（见上），与旧数字不可直接比较。

## 验证

开发机上的自动化检查全部通过：`cargo test --lib` 193 项、`cargo clippy --all-targets` 零警告、`cargo fmt -- --check`、`tsc --noEmit`、`npm run lint`、`npm run build`、`npm test`（18 个文件 210 项）。

自动化测试够不到托盘、朗读引擎与全局热键，所以请按 `docs/QA-machine-checklist-v1.6.md` A/B/C 组与 `docs/QA-machine-checklist-v1.9.md` F–K 组在 Windows 实机验收。其中最需要实机确认的是：

- 托盘里「划词即查」的勾选随点击与设置页的开关同步；「暂停 30 分钟」后再点一次「划词即查」可取消暂停。
- 设置页的语音试听与实际朗读是同一个声音；没有任何英文语音的机器上，朗读退回系统默认语音。
- 复制含弯引号的英文（如 `don’t`、`it’s`）后点击朗读，能正常发声。
- 关闭「记录查词历史」后查词，历史页不再增加记录，已有记录仍可查看与删除。
