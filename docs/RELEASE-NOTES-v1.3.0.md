# 鸽鸽词典 v1.3.0

v1.3 建立了面向个人工作语境的术语与领域能力，并包含 v1.1、v1.2 的隐私、学习和版本送达改进。

## 新功能

- 个人术语表：新增、编辑、启停、删除、搜索及按领域筛选术语。
- 批量迁移：支持 JSON / TSV 导入导出，并可选择跳过或覆盖重复术语。
- 领域 Profile：通用、计算机、医疗 / IVD、金融、法律五种模式。
- 解析风格：简洁、标准、深度三档，和现有 Prompt 模板协同工作。
- 学习闭环：三档轻量复习、阅读会话聚合、批量标记与导出。
- 安全更新：应用内检查、下载并验证签名更新包。

## 体验与可靠性

- DeepSeek 等 OpenAI 兼容接口支持流式响应，并修复触发翻译后长期加载的问题。
- API Key 使用 Windows DPAPI 加密保存；敏感剪贴板内容在发送模型前拦截。
- 数据库升级前自动备份，v1.3 schema 迁移失败时安全回滚。
- 更新检查对发布源未就绪、网络超时和签名失败提供更明确的提示。

## 升级说明

- 支持 Windows 10 1803 及以上、Windows 11。
- 从旧版本安装或应用内升级都会保留生词库与设置，并自动迁移数据库。
- 首次发布自动更新通道后，v1.0.0 用户需要手动安装本版本；之后可直接在应用内升级。
