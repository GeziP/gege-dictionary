# 鸽鸽词典 v1.4.0

V1.4 聚焦计算机与医疗 / IVD 两个领域，把原本的一句 Profile 偏好升级为结构化专业解析。

## 计算机领域

- 按内容相关性展示核心机制、执行或数据流程、算法步骤与复杂度。
- 代码和伪代码使用专用卡片，保留缩进、支持横向滚动和一键复制。
- 明确工程边界与权衡；非算法概念不再强行生成复杂度或代码。

## 医疗 / IVD 领域

- 展示检测原理、上下文明确给出的样本类型、分析物和前分析 / 分析 / 后分析流程。
- 分开展示临床意义、性能指标、干扰因素、质量控制、局限和标准口径。
- 不猜测样本、分析物、阈值、参考区间或患者结论；标准需直接相关且版本明确。
- LoB、LoD、LoQ 等指标不把简化统计规则描述为普适公式，并固定提示内容不构成个体诊疗建议。

## 术语体验

- 不导入任何文件也可直接使用领域 Profile。
- 支持从 Excel / WPS 粘贴“英文术语、固定译法、可选备注”两列或三列。
- JSON / TSV 文件操作移入“批量迁移与备份”，保留团队共享和版本管理能力。

## 兼容性

- `domainAnalysis` 是可选字段，V1.3 及更早的缓存、收藏和数据库不需要迁移。
- 阻塞、流式、缓存和收藏均保留新的领域结构。
- 流程由本地 UI 根据结构化步骤绘制，不执行模型生成的 HTML、脚本或 Mermaid。
