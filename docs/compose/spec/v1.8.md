## [S1] Problem

v1.7 交付后仍留下：

1. 生词库无排序功能，词条积累后难以管理。
2. 批量操作缺少掌握度调整，只有标签/删除/导出/Anki。
3. `lib.rs` 2727 行，lookup/settings/窗口/OCR 混杂，改动风险高。

## [S2] Design

### E0 生词库排序
- WordTable 表头（单词/收藏时间/查询次数/掌握度）可点击切换 asc/desc。
- Library 维护 `SortState`，`useMemo` 对 filtered 结果排序后传入 WordTable。
- 默认 savedAt desc（最新在上）。

### E1 批量掌握度
- LexNoteContext 新增 `batchSetMastery(ids, mastery)`，逐条调 `updateWord`。
- SelectionBar 增加掌握度 `<select>` 下拉，选中即触发。

### E2 lib.rs 模块拆分
- 新建 `lookup.rs`，迁移 PreparedLookup / prepare_lookup / lookup_word / lookup_word_stream / test_connection 等。
- lib.rs 共享函数（normalize_selection / cache_ttl_days / record_event*）标 `pub(crate)`。
- generate_handler! 改为 `lookup::lookup_word` 等路径。
- 对应测试一并迁移。

## [S3] Out of Scope

Authenticode（#14）、RapidOCR、db.rs 拆分、完整 SRS、云同步。
