# v1.6 截图 OCR · Anki · 上下文 · 查词窗体验

## Report

**What was built** — 系统级截图 OCR（WinRT + GDI，热键/托盘/框选，结果进既有 Lookup 管道并过 content_filter）；可选 AnkiConnect（强制 loopback，设置页测试连接/牌组，生词详情一键发送与 Front 去重）；查词窗可编辑上下文重解析；重用窗口改为事件重置不再 `location.reload()`。版本三处 1.6.0，README 与 RELEASE-NOTES 已同步。

**Verification** — `cargo test --lib` **102 passed / 1 ignored**；`npm test` 14 passed；`tsc` / `lint` / `vite build` / `cargo fmt --check` 全 PASS。独立审查 C1（遮罩被 BitBlt）与 C2（WinRT 线程 COM 初始化）已在 `a54633d` 修复；同步补 Anki Extra/enabled 校验与热键注销。

**Journey log**
1. 全屏遮罩内 BitBlt 会截到自己——必须先 `hide()` 再截屏。
2. `spawn_blocking` 里跑 WinRT 必须 `CoInitializeEx(MTA)`，否则间歇性失败。
3. 双端注册 global-shortcut 易双触发；关闭开关要走 unregister。
4. Anki 带 Extra 字段可能被 Basic 模型拒绝，需 Front/Back 回退。
5. 多显示器主屏外 BitBlt 仍有限制，已知 follow-up。

## [S1] Problem

v1.5 后主场景与隐私已稳，但仍缺：扫描件/字幕无法 Ctrl+C；生词进 Anki 仍靠手工 TSV；context≈selection 语境弱；查词窗 reload 闪白、空态不可操作。

完整规格：`docs/PRD-v1.6-spec.md`。

## [S2] Design

### O0 截图 OCR
- 热键默认 `Ctrl+Shift+O`；托盘「截图取词」；全屏遮罩框选。
- 截屏前隐藏遮罩 → GDI BitBlt → 内存 PNG → WinRT OCR（COM MTA）。
- 结果走 `content_filter` + Lookup 管道；`sourceApp=screenshot`。
- 设置：`ocr.enabled` / `hotkey` / `language`；关闭时 unregister 热键。

### O1 Anki Connect
- 默认关；仅 loopback；`enabled=false` 时后端拒绝请求。
- Front=lemma，Back=译文+语境；Extra=explanation（失败回退 Front/Back）。
- 去重：`deck:"x" Front:"lemma"`。

### O2 上下文
- 查词窗可编辑 context → 强制刷新重新解析。

### O3 查词窗
- 重用窗口 `gege-lookup-reset` / CustomEvent，不再 reload。

## [S3] Out of Scope

云 OCR、云 Anki、完整 SRS、Authenticode、双路径合并、多显示器虚拟屏、auto_send 实际行为。
