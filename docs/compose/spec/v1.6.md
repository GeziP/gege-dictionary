# v1.6 截图 OCR · Anki · 上下文 · 查词窗体验

## Report

## [S1] Problem

v1.5 后主场景与隐私已稳，但仍缺：扫描件/字幕无法 Ctrl+C；生词进 Anki 仍靠手工 TSV；context≈selection 语境弱；查词窗 reload 闪白、空态不可操作。

完整规格：`docs/PRD-v1.6-spec.md`。

## [S2] Design

### O0 截图 OCR
- 热键默认 `Ctrl+Shift+O`；托盘「截图取词」；全屏遮罩框选。
- GDI BitBlt 截区域 → 内存 PNG/BMP → WinRT `Windows.Media.Ocr`（en-US）。
- 结果走 `content_filter` + 现有 Lookup 管道；`sourceApp=screenshot`。
- 设置：`ocrEnabled`/`ocrHotkey`/`ocrLanguage`。
- 事件：`ocr_triggered`/`ocr_filtered`。
- 引擎不可用：可读错误，不注册崩溃。

### O1 Anki Connect
- 默认关；仅 `http://127.0.0.1:8765`（可配端口）。
- api v6：`requestPermission`/`deckNames`/`modelNames`/`addNote`/`findNotes`。
- Front=lemma，Back=translation+context；tags 含领域与来源。
- 重复发送：findNotes by deck+front 或 `anki_note_id`。
- Commands：`test_anki_connection`/`list_anki_decks`/`list_anki_models`/`send_words_to_anki`。

### O2 上下文
- 查词窗可编辑 context → 重新 invoke lookup。
- 默认行为与 v1.5 一致。

### O3 查词窗
- 重用窗口不 `location.reload()`，改事件重置。
- 空态：未识别 / 已过滤 / 无 Key / 网络失败。

## [S3] Out of Scope

云 OCR、云 Anki、完整 SRS、Authenticode、双路径合并、多语种 OCR。
