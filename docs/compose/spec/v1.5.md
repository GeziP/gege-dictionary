# v1.5 主场景与隐私运行时

## Report

## [S1] Problem

v1.4.4 数据链路已稳，但主场景与隐私卖点仍有缺口：

1. 默认黑名单把 IDE/终端写死拦截，开发者复制英文文档不弹窗。
2. `is_code_snippet` 单行前缀误杀自然英语（`import the data from Excel`）。
3. `csp: null`，`eprintln!` 可能打印 selection，`get_settings` 下发明文 API Key。
4. ROADMAP Success Metrics 无本地可核验数据。
5. 无 PR CI；#1/#3/#4 过时仍 OPEN。

完整产品规格见 `docs/PRD-v1.5-spec.md`（本仓库权威验收清单）。

## [S2] Design

### 黑名单

- `DEFAULT_BLACKLIST` 仅密码管理器：`1password`, `keepass`, `bitwarden`, `lastpass`。
- 新增设置 `lookupInIde`（默认 `true`）、`ideBlacklist`（默认含 code/devenv/idea/cursor/终端）。
- `lookupInIde=false` 时才用 `ideBlacklist` 拦截；自定义黑名单始终生效。

### 过滤

- `FilterReason` 枚举 + `reject_reason()`；`should_reject` 委托之。
- 弱语境前缀（import/from/type/const/let/var/class/def/fn…）需强语境合取才拒。
- 安全类（secret/path/base64/email/ip）行为不变。

### 隐私

- `tauri.conf.json` 最小 CSP；实机可过主流程。
- 日志：长度/kind/哈希，无 selection/context/Key 原文。
- `get_settings` 屏蔽 `provider.apiKey` 明文；save 时占位符保留原密文。

### 本地观测

- Schema v4：`local_events(date, event, count, extra)` 按日 upsert，保留 90 天。
- Commands：`get_local_metrics(days)`, `clear_local_metrics()`。
- 设置页「本地统计」只读 + 清除。

### 工程

- `.github/workflows/ci.yml`：tsc + lint + build + cargo test。
- 版本 bump 1.5.0；关闭过时 Issue 在交付说明中列出。

## [S3] Out of Scope

- 截图 OCR、Authenticode、Anki Connect、合并 lookup 双路径、新领域、云同步。
