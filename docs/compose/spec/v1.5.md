## [S2] Design

### 黑名单

- `DEFAULT_BLACKLIST` 仅密码管理器：`1password`, `keepass`, `bitwarden`, `lastpass`（所有触发模式始终拦截）。
- 新增设置 `lookupInIde`（默认 `true`）、`ideBlacklist`（默认含 code/devenv/idea/cursor/终端）。
- `lookupInIde=false` 时才用 `ideBlacklist` 拦截；自定义黑名单始终生效。

### 过滤

- `FilterReason` 枚举 + `reject_reason()`；`should_reject` 委托之。
- 弱语境前缀（import/from/type/const/let/var/class/def/fn…）需强语境合取才拒。
- 安全类（secret/path/base64/email/ip）行为不变。

### 隐私

- `tauri.conf.json` 最小 CSP；实机可过主流程。
- 日志：长度/kind/哈希，无 selection/context/Key/译文原文。
- `get_settings` 屏蔽 `provider.apiKey` 明文；save 时占位符/空且已有密文则保留原密文。

### 本地观测

- Schema v4：`local_events(date, event, count, extra)` 按日 upsert，保留 90 天。
- Commands：`get_local_metrics(days)`, `clear_local_metrics()`。
- 事件：clipboard_filtered/triggered、cache_hit/miss（含流式路径）、stream_first_field/fallback、review_card_answered、reading_session_viewed、glossary_term_applied。
- 设置页「本地统计」只读 + 清除。

### 工程

- `.github/workflows/ci.yml`：tsc + lint + vitest + build + cargo fmt + cargo test。
- 版本 bump 1.5.0；CaptureMethod 移除未实现的 `uia`。

## [S3] Out of Scope

- 截图 OCR、Authenticode、Anki Connect、合并 lookup 双路径、新领域、云同步。
