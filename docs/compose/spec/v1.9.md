## [S1] Problem

v1.8 交付后，通读代码发现的问题不在「缺功能」，而在已有功能里的信任债：

1. **安全**：朗读文本被拼进 PowerShell 源码，弯引号可逃出字符串。
2. **数据**：再次查已收藏的词会整体覆盖它（掌握度 / 备注 / 标签重置，Anki 关联丢失，还会重复）；Anki note id 按位置配对会写到别的词上。
3. **说了没做**：「撤销收藏」只翻转按钮；「重新解析」不调用模型；「今日查询」其实是「今日保存」，token 恒为 0；首次配置的连接测试写死 412ms。
4. **状态不同步**：托盘「划词即查」勾选与实际状态不一致，「暂停 30 分钟」不可取消且会覆盖用户之后的关闭。
5. **体验**：查词窗口对任何按键响应；403 / 404 / 429 / 5xx 与超时都显示「请检查网络」；用系统默认（中文）语音读英文；所有错误横幅没有底色。
6. **工程**：`main` 上 rustfmt 失败使 CI 红灯；21 个无人引用的文件；10 参数的函数与 10 元素元组；clippy 二十余条警告。
7. **功能缺口**：查过但没收藏的词无处找回；没有地方回答「我学得怎么样」。

完整清单与后果见 `docs/ROADMAP-v1.9-v2.0.md` §1.2；规格见 `docs/PRD-v1.9-spec.md`。

## [S2] Design

### E0 信任债
- 每个问题先复现，再修，再用一个「修之前会失败」的测试守住。
- TTS：文本 / 语音 / 语速走 `GEGE_TTS_*` 环境变量，脚本为编译期常量。
- 保存：`save_lookup_result` 合并，按 id 或「归一化 lemma + kind」识别。
- 错误：每个出口按真实原因打码；前端按码给标题 / 建议 / 动作。
- 计数：`finish_lookup()` 是所有出口的汇合处，统一计数、写缓存、记历史。

### E1 查词历史
- `lookup_history`，一个 `history_key` 一行，保留最近 500 条，默认开启可关闭；历史页分组 / 搜索 / 再次打开 / 删除 / 清空。
- 旧版本备份恢复时按其自身版本校验并立即升级；更新版本的备份被拒绝。

### E2 学习洞察
- 统计逻辑是 `insights.rs` 的纯函数（传入当天日期，不读时钟）；`db.rs` 只取数；页面 `/insights`，7 / 30 / 90 天。
- 连续天数：任何活动算一天，今天未学不算断。

### E3 托盘与朗读
- `WatchSwitch`：开 / 关 / 暂停三个动作共享一个状态；暂停只在仍是最后一次改动时自己结束。
- 托盘勾选通过类型擦除的闭包更新，`AppState` 不持有 `Wry` 类型（否则测试可执行文件无法启动，见规格 §7.3）。
- 语音：指定名 → en-US → 任一英文 → 系统默认；设置页原生试听。

### E4 工程与性能
- clippy 清零；`library-list.ts` 纯函数 + `useDeferredValue` + memo 行；全选只针对当前列出的词。
- 耗时预算类测试：在绝对预算内，或与同机器上已知线性开销的参照相比成比例。
