# 鸽鸽词典 v1.4.3

本版本把数据迁移、备份、恢复和导入流程收敛到可校验、可回滚的本地工作流，并补齐前端状态与系统实际状态的一致性。

## 可靠性修复

- 备份、迁移和完整导出统一使用 SQLite Online Backup API，覆盖 WAL 中尚未 checkpoint 的数据，并在落盘前执行完整性和 schema 契约校验。
- 自定义数据目录失联时进入显式恢复流程；迁移目标必须为空，只复制受管理的备份文件，原数据库保留，失败不会切换活动连接或数据目录指针。
- 重新定位数据目录时兼容仍可迁移的旧版 schema，同时拒绝完整性失败或最新版本缺少关键表结构的数据库。
- 恢复前创建可见的安全快照；恢复失败会自动回滚。自动备份按本地自然日执行，最多保留 10 份自动备份。
- CSV/TSV 生词导入支持 BOM、引号、换行和逐行错误报告，提交时仍限制 10 MB / 10,000 行并在单个 SQLite 事务中合并。
- 导出全部数据使用原生保存对话框输出一致性 SQLite 快照；API Key 在 Windows 上以 DPAPI 密文保存，换机器后需要重新配置。

## 行为修复

- 剪贴板去重使用 Windows 剪贴板序列号；同一内容重新复制后可以再次查词，来源应用进程名与窗口标题分开记录。
- 流式请求在首字节前失败时只降级一次非流式请求；已收到增量后失败只显示可重试错误，避免重复计费。
- 开机自启通过 Tauri 官方插件读取和写入操作系统真实状态，启动参数包含 `--minimized`。
- 设置保存串行化并在失败时回滚乐观 UI；迁移或恢复成功后重新加载词条、设置、模板、用量和数据目录信息。

## 验证边界

自动化 Rust、TypeScript、Vitest、Lint、生产构建和 CI 发布门禁已通过。正式发布仍需要在 CI 提供 `TAURI_SIGNING_PRIVATE_KEY`，并在隔离的临时 `%APPDATA%` 下完成一次 Tauri 实机回归。
