# v1.6 实机验收清单

适用版本：1.6.0 + 修复提交 `7a6108d`  
目的：自动化门禁与浏览器 mock 无法覆盖的原生路径，在装有 Windows 的真机上逐项验收。

## 环境前置

| 项 | 要求 |
|---|---|
| OS | Windows 10 1809+ / Windows 11 |
| OCR 语言包 | 设置 → 时间和语言 → 语言 → 英语（美国）识别包 |
| Anki | 桌面版已启动，安装 AnkiConnect（默认 `127.0.0.1:8765`） |
| 显示器 | 至少一台副屏（或缩放 ≠100%）用于多屏 OCR |
| 安装包 | `Gege-Dictionary_1.6.0_x64-setup.exe` 或本地 `npx tauri build` 产物 |

## A. 复制即查（主路径）

| # | 步骤 | 期望 |
|---|------|------|
| A1 | 浏览器选中英文句子 → Ctrl+C | 弹出查词窗，无闪白 reload |
| A2 | VS Code 复制英文注释 | 默认弹窗（`lookupInIde=true`） |
| A3 | 复制 `192.168.1.1` 或 API Key | 不弹窗、不发送；设置 → 本地统计可见过滤原因 |
| A4 | 复制 `12:30:45` | **不**被当 IPv6 拦截（`7a6108d` 修复） |
| A5 | 连续三次 Ctrl+C 查词 | 窗口复用，无白屏闪烁 |

## B. 截图 OCR

| # | 步骤 | 期望 |
|---|------|------|
| B1 | 主屏 Ctrl+Shift+O，框选扫描 PDF 英文 | 弹出查词窗；`sourceTitle` 为前台窗口标题 |
| B2 | 副屏上框选（光标在副屏） | 遮罩出现在光标所在屏；识别内容与框选区域一致 |
| B3 | 混合 DPI（125%/150%）副屏框选 | 截取区域无明显偏移 |
| B4 | 无英文空白区域 | 提示「未识别到英文」，不写缓存 |
| B5 | 设置关闭「截图取词」 | 热键失效；托盘无「截图取词」项；设置页「立即框选」亦拒绝 |
| B6 | 修改热键为 `Control+Alt+O` 并失焦 | 新热键生效，旧热键失效 |

## C. Anki Connect

| # | 步骤 | 期望 |
|---|------|------|
| C1 | 未启用 Anki 时抓包/断网 | 无 `127.0.0.1:8765` 请求 |
| C2 | 启用并「测试连接」 | 显示 API 版本与牌组列表 |
| C3 | 生词详情 → 发送到 Anki | Anki 中可见；Back 含译文+语境；Extra 含解释+例句（若有） |
| C4 | 重复发送同一 lemma | 不产生重复卡 |
| C5 | Anki 未启动时发送 | 错误文案可操作；本地统计 `anki_send_fail` |
| C6 | 开启 autoSend 后收藏 | 收藏成功后尝试同步（Anki 未开则静默失败） |

## D. 本地统计与隐私

| # | 步骤 | 期望 |
|---|------|------|
| D1 | 完成 A/B/C 后打开设置 → 本地统计 | 可见 OCR 触发/过滤、Anki 成功/失败与 OCR 成功率 |
| D2 | 日志目录搜索选区原文 / API Key 明文 | 不得出现 |
